# 作者台账（不发布）

本文件是 `manifest.json` 的 `notes` 字段**公开前**的原文，2026-11-18 从 manifest
挪出。原因：`_casting` 是 manifest 的合法字段，会原样进市场——我曾以为它
「不对外投影」，实测线上 v5 里能看到整段（含「内部元团队」字样）。所以作者
台账不能放在 manifest 的任何字段里。

保留它的理由：它是铸造过程与历史裁决的记录，删掉就查不到「当初为什么这么写」。
