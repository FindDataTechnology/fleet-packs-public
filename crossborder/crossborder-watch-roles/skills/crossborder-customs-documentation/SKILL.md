# 跨境电商关务单证要素技能

## 监管代码目录（单列纪律）
- 9610：跨境电商零售出口（B2C 直邮/集货）
- 1210：保税跨境电商（保税仓备货，含出口/进口分向）
- 9710：跨境电商 B2B 直接出口
- 9810：跨境电商出口海外仓
- 1039：市场采购贸易方式
- 0110：一般贸易
- 代码必须与政策条款原文一并摘录，不脱文解释；不确定适用面只写原文并标「原文未释」；多代码逐代码分行列出，禁合并

## 单证字段映射纪律
- 仅映射海关/口岸公开规范字段（申报单元、监管方式、征免性质、法定单位等）
- 字段名与规范原文一致，不自造别名
- 缺位字段如实标注「规范未覆盖」，不补齐

## 申报要素归一化
- 按监管代码维度归一：同一代码下要素按规范顺序排列
- 变动要素（如税率、监管条件）标注生效日期与公告号
- 仅做结构化，不做合规建议

## 输出契约
- 产出：代码目录表、字段映射表、要素变动表
- 收尾必 report_status，槽位：code_catalog_version/field_map_count/element_changes
- 遵守 fleet-data-qa 共用层只读纪律
